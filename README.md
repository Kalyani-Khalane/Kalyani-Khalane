## Featured Project — Smart Newspaper Highlighter

**[View Repository →](https://github.com/Kalyani-Khalane/smart-newspaper-highlighter)**

*Next.js · Python · Flask · SQLite · SQLAlchemy · spaCy · scikit-learn · Tailwind CSS*

### Project Overview

A full-stack platform that automatically ingests daily news from live sources, classifies each article by relevance to competitive exams (UPSC/MPPSC), and presents it in a focused reading interface built for daily use, which turns an overwhelming, manual news-scanning habit into an automated, structured workflow.

### Project Breakdown

**Situation** — Competitive exam aspirants need to stay current with daily news, but manually sifting through dozens of sources to find exam-relevant articles is slow and easy to fall behind on.

**Task** — Design and build a full-stack system that ingests news automatically, filters it for exam relevance without human curation, and gives the user a fast, distraction-free way to read and retain what matters.

**Action** — Built a 7-table relational schema with SQLAlchemy/SQLite to structure ingested content; engineered an asynchronous Python pipeline to pull live articles from NewsAPI and RSS feeds; applied TF-IDF vectorization and scikit-learn classification models to automatically tag articles by exam relevance; designed a Next.js/TypeScript reading interface with a custom PDF note-export feature using jsPDF.

**Result** — A working end-to-end system that replaces a manual, repetitive research task with an automated pipeline i.e built as my capstone project to demonstrate full-stack architecture combined with applied NLP, not just frontend or backend in isolation.

### Key Features

- Automated ingestion from live RSS feeds and NewsAPI, running asynchronously
- NLP-based classification pipeline that scores and tags articles for exam relevance
- Structured, normalized database layer instead of flat/unstructured storage
- Distraction-free, purpose-built reading interface for daily use
- One-click PDF note generation for saving and reviewing key articles

### Tech Stack

| Layer | Technologies |
|---|---|
| Frontend | Next.js, TypeScript, Tailwind CSS |
| Backend | Python, Flask |
| Database | SQLite, SQLAlchemy (7-table schema) |
| NLP / AI | spaCy, scikit-learn, TF-IDF |
| Data Sources | NewsAPI, RSS feeds |
| Utilities | jsPDF (note export) |
